# Happy Gadgets

A single-page catalog site for Happy Gadgets, a gadget shop at New Pioneer Mall PA85. Every product and
category links out to a pre-filled WhatsApp chat for ordering — there's no cart or checkout.

## Development

You'll need Node.js.

```sh
git clone <this-repository-url>
cd <repository-name>
npm i
npm run dev
```

## Built with

- TanStack Start
- TypeScript
- React
- Tailwind CSS
